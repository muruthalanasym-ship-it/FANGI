# FANGI CARPENTRY website

A responsive single-page website for FANGI CARPENTRY, with a warm wood-inspired visual theme, a vector logo based on the provided reference, professional carpentry service descriptions, and direct links to WhatsApp, Facebook and Instagram.

## Preview locally

Open `index.html` in a browser. The page uses Google Fonts and Unsplash-hosted photography, so an internet connection is needed for those assets. The logo is stored locally in `assets/fangi-logo.svg`.
